# Sales Data Analysis Using Python

## Project Overview

This project focuses on analyzing sales data using Python and Jupyter Notebook. The project uses a CSV dataset to calculate important sales information and understand business performance.

## Technologies Used

- Python
- Jupyter Notebook
- CSV
- VS Code

## Key Analysis

This project performs the following analysis:

1. Calculate total revenue from all sales.
2. Count the total number of orders.
3. Calculate the total quantity of items sold.
4. Analyze sales data using Python.
5. Extract useful information from the CSV dataset.

## Dataset

The project uses `orders.csv` as the source dataset for sales analysis.
